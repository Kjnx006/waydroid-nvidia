Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Fixed a GPU crash from rc12's async compute queue.** Vulkan apps that copy memory with indirect copy commands
  on the compute queue crashed the GPU channel (Xid 32) on RTX 20, 30, 40 and 50 and Titan V. These copies now
  run correctly.
- **Fixed two Android display freezes.** The screen could freeze for about 30 seconds, then Android restarted its
  UI:
  - when an app took keyboard focus while Android was reconfiguring the display, for example when opening the
    Play Store over a running game (#38, fixed upstream in Waydroid's hwcomposer; thanks @jngviniciusneri for
    tracking it down);
  - when many app windows were opened or switched quickly.
- **App windows resize Android.** Without multi-window mode, resizing an app's own window now resizes the
  Android display instead of scaling the app with black bars (#35, thanks @hyzor).

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Supported GPUs, drivers and known
issues are in the [README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
